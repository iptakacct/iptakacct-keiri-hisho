# 達人シリーズでの読み込み確認の手順（実機確認）

kessan が出す達人用のXML（4種類）が、実際の達人で読み込めるかをオーナーに確かめてもらうための手順書です。確かめた結果は、このファイルの末尾の「結果」の欄に書いてください（書くのは一言ずつで足ります）。

読み込めなかったときも、それ自体が大事な結果です。画面のメッセージをそのまま書き写すか、スクリーンショットを残してください。

## 1. 確かめること（全体像）

| 種類 | 読み込む先 | 読み込み方 |
|---|---|---|
| 決算書（HJ21） | 法人税の達人（決算書の作成） | 「中間ファイル（決算書用）からのインポート」 |
| 内訳書（UG13）・概況書（UG16） | 内訳概況書の達人 | データ取り込み（XML） |
| 消費税（SY35） | 消費税の達人 | データ取り込み（XML） |

## 2. 試すファイルを用意する

ファイルは架空の会社（実在の会社の情報は入っていません）の1年分から作ります。次のどちらかで用意します。

### 方法A（おすすめ）：秘書（Claude）に架空の会社のサンプルを作ってもらう

秘書（Claude Code）に「達人の読み込み試験用のサンプルを作って」と頼んでください。自分でコマンドを打つ必要はありません。

参考までに、秘書が実行するコマンドは次のものです。

```
cd <リポジトリのフォルダ>\.claude\scripts\kessan
python -m pytest -q tests/test_statements_flow.py --basetemp=C:\kessan-sample-new
```

注意：`--basetemp` に指定したフォルダは、実行のたびに**中身がすべて消されます**。必ず**まだ存在しない新しいフォルダ名**（上の `C:\kessan-sample-new` のようなもの。2回目以降は `C:\kessan-sample-new2` のように名前を変える）にしてください。書類や既存のフォルダの名前を指定してはいけません。

うまくいかないとき（エラーが出る、「2 passed」と出ない）は、出た文面をそのまま秘書に見せて、直してもらってください。Python と pytest はこのリポジトリの環境に入っているので、新しく入れるものはありません。


「2 passed」と出れば成功です。次のフォルダに4種類のXMLができています。

```
C:\kessan-sample-new\test_statements_and_export_flo0\インスタンス\work\kessan\2026-03期\output\tatsujin\
    kessan-HJ21-20260331.xml      決算書
    uchiwake-UG13-20260331.xml    内訳書
    gaikyo-UG16-20260331.xml      概況書
    shohizei-SY35-20260331.xml    消費税
```

このファイルの会社名は空です。会社名が入った決算書も見たいときは、`C:\kessan-sample-new\test_company_name_is_written0\…\output\tatsujin\kessan-HJ21-20260331.xml`（会社名は「テスト商事株式会社」）を使います。

### 方法B：自分の会社の帳簿から出す

決算整理の登録まで終わった年度フォルダ（例：`work\kessan6-03期`）で、次を実行します（秘書に頼んでもかまいません）。`<会社名>` はその会社の本当の名前に置き換えます。**架空の名前を入れないでください**（`period.yaml` に書かれ、決算書の顧問先名になります）。試しに別の名前で出したいときは、年度フォルダを丸ごとコピーしたものに対して実行してください。

```
python ..\.claude\scripts\kessan\cli.py init --year-dir work\kessan6-03期 --start 2025-04-01 --end 2026-03-31 --company-name <会社名>
python ..\.claude\scripts\kessan\cli.py statements --year-dir work\kessan6-03期
python ..\.claude\scripts\kessan\cli.py export-tatsujin --year-dir work\kessan6-03期
```

出力は `work\kessan6-03期\output	atsujin\` に入ります。`init` は既にある年度フォルダに会社名だけを足します（帳簿は消えません。期間は実際の期首日・期末日に合わせてください）。

## 3. 読み込んで確かめる

決算書 → 内訳書・概況書 → 消費税の順に、1つずつ読み込みます。読み込めた・読み込めないにかかわらず、確かめることを下に挙げます。

### 3-1. 法人税の達人：決算書（kessan-HJ21-….xml）

1. 「決算書の作成」の「中間ファイル（決算書用）からのインポート」で、決算書のXMLを選ぶ
2. 読み込めたか。エラーが出たら、そのメッセージを書き写す（特に、作成元の名前 `kessan` が知らないものとして断られていないか）
3. 取込設定の画面で、科目がどう対応付いたか（達人にある科目に自動で当たったか、「ユーザー独自の科目」になったか）。対応しなかった科目名を書き留める
4. 貸借対照表の資産の部に、減価償却累計額がマイナスの項目として入り、有形固定資産の合計（485,000円）が合うか
5. 繰越利益剰余金が、期首の繰越利益剰余金ではなく当期純利益を含んだ額（△421,364円）として入っているか。株主資本等変動計算書の当期純利益が合うか
6. 決算書の表示パターン（貸倒引当金・減価償却の表示方法など、決算書の設定の選択肢）が、読み込み後どうなっているか。画面の選択肢の名前を書き留める（XMLの `PATTERN` の値 A2・B5・C2・D5・E1・F3・G1 がどの選択肢に当たるかを知るため）
7. 達人で法人税等を計算し直した後、達人側の決算書の税引前当期純利益が △351,364円になっているか

### 3-2. 内訳概況書の達人：内訳書（kessan-UG13-….xml）・概況書（kessan-UG16-….xml）

1. 内訳書のXMLを読み込めたか。エラーなら、メッセージを書き写す
2. 勘定科目ごとの期末残高と、補助科目ごとの残高が入っているか（普通預金のサンプル銀行が916,000円）
3. 繰越利益剰余金が、どの内訳書のどの欄に入ったか（期末残高そのもの。当期純利益は含まない）。入らなかったか
4. 減価償却累計額（55,000円）が、どの内訳書のどの欄に、どちらの符号で入ったか
5. 概況書のXMLを読み込めたか。主要科目（売上高 1,210,000円、役員報酬 1,320,000円、資産の部 1,747,000円など）が入っているか
6. 月別の売上等が、期首の月（4月）から数えた月に入っているか（6月に1,100,000円、3月に110,000円）。月別の人件費が4〜9月は100,000円、10〜3月は120,000円か

### 3-3. 消費税の達人：消費税（kessan-SY35-….xml）

1. 読み込めたか。エラーなら、メッセージを書き写す
2. 課税売上（10%）の税抜額1,100,000円と税額110,000円、課税仕入（10%）の税抜額586,364円と税額58,636円が入っているか
3. 課税方式の区分（XMLの `KAZEIKUBUN` に 1 を入れています）が、達人の画面でどの区分として読まれたか（原則課税になっているか）。1以外に何があるかも画面の選択肢で見ておく
4. 割戻し計算・全額控除として読まれているか
5. 経過措置の80%・50%の仕入がある会社で試すときは、税額が「控除割合を掛ける前の額」として入り、達人の側で80%・50%が掛かっているか（この架空の会社には経過措置の仕入が無いので、方法Bで経過措置のある会社を出して確かめる）
6. 要素の合計がマイナスになる会社（売上より返還が大きいなど）を読み込んだとき、達人がマイナスの金額を受け付けるか。受け付けない場合、どの欄でエラーになるか（この架空の会社にはマイナスの欄が無いので、該当する会社があるときだけ確かめる）

### 3-4. 全体で確かめること

- 使っている製品とエディション：法人税の達人・内訳概況書の達人・消費税の達人それぞれの Professional・Standard・Lightのどれか。連動コンポーネントなどの有償オプションの有無
- XMLの `PROGRAMNAME` が `kessan` のままで、どの達人も受け付けるか（断られたら、MFやfreeeと同じ名前に変えられるかを決めるので、断られたメッセージを書き写す）
- 画面で出た警告の文言

## 5. 結果の使い方

- 読めたものは「引き渡しファイルを作る対象」として `tatsujin-import.md` の §5 に記入します（記入はこちらで行います。上の表を見せてください）
- 読めなかったものは、画面のメッセージをもとに XML の形を直すか、材料のExcel（`uchiwake-material.xlsx`・`gaikyo-material.xlsx`・消費税の集計表）を見ながら手で入力する運用に切り替えます
- 表示パターンの意味が分かったら、決算書XMLの表示パターンを設定で選べるようにするかを決めます
