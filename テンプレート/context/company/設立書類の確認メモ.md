# 設立書類の確認メモ（定款・登記簿・株主名簿）

受任したら最初に、定款・履歴事項全部証明書（登記簿）・株主名簿を受け取り、このメモを埋める。
原本は `context/company/source/定款/`・`source/登記簿/` に置き、中身の書き起こしは各フォルダの `README.md` に書く（`.claude/rules/source-materials.md`）。
**書類で確認した値だけを書く。** 推測で埋めない。空欄は「未確認」のまま残す。

## 2. 事業年度（決算・申告の期間を決める）

| 項目 | 値 | 出典 | 転記先 |
|---|---|---|---|
| 事業年度 | 毎年 月 日〜 月 日 | 定款「事業年度」 | `tax-profile.md` `fiscal_year_start`・`fiscal_year_end` |
| **最初の事業年度** | 成立日〜 | 定款 附則「最初の事業年度」 | ― |
| 会計ソフトの期首 | | freee・MFの事業年度設定 | ― |

- ⚠️ **第1期は「会社成立の日」から始まる。** 会計ソフトの期首が成立日より前（事業年度の定型の開始日）になっていないか確認する。
  ずれていれば、成立前の日付の仕訳（開業費・創立費・設立前の資産取得）の扱いと、ソフトの期首の直し方を決算前に決める
- 定時株主総会は「事業年度終了後◯か月以内」。申告期限の延長の特例を使うかの判断材料になる

## 3. 資本・株式・株主（同族会社判定・均等割に使う）

| 項目 | 値 | 出典 | 転記先 |
|---|---|---|---|
| 資本金 | | 登記簿・定款 附則 | `tax-profile.md` `capital`・`capital_etc` |
| 発行済株式数 | | 登記簿 | ― |
| 発行可能株式総数 | | 定款 | ― |
| 株式の譲渡制限 | あり／なし | 定款 | ― |
| 株主と持株数 | | 定款 発起人条項（設立時）・株主名簿（現在） | `tax-profile.md` `is_family_company` |

- 定款の発起人条項は**設立時点の株主**。その後の譲渡・増資は株主名簿で確かめる
- **株主と役員が別人か**を見る。別人なら、役員報酬の決議・株主からの借入・株主が支配する会社との取引が、それぞれ独立した論点になる
- 株主本人・株主の会社からの入金（貸付・立替・出資）は、仕訳の前に性質（借入／増資／立替精算）を確認する

## 4. 役員と役員報酬（定期同額給与の判定に使う）

| 項目 | 値 | 出典 | 転記先 |
|---|---|---|---|
| 取締役・代表取締役 | | 登記簿 | `tax-profile.md` `officers` |
| 取締役会の有無 | | 定款「員数」・登記簿 | ― |
| 取締役の任期 | | 定款 | 任期満了の変更登記の時期 |
| **役員報酬の決め方** | 株主総会決議／取締役会一任 など | 定款「報酬等」 | ― |
| 役員報酬の決議日・月額・支給開始月 | | 株主総会議事録 | `tax-profile.md` `officers[].changed_on` |

- ⚠️ **役員報酬を始めた月・変えた月が、期首（第1期は成立日）から3か月以内の決議に基づくか**を議事録で確かめる。
  外れていれば定期同額給与に当たらない部分が損金不算入になりうる
- 任期満了の変更登記を忘れると過料の対象になる。満了する事業年度を控えておく

## 5. 読み取って分かった論点（会社ごとに書き足す）

- （例）第1期の期首と会計ソフトの期首がずれている
- （例）株主と役員が別人で、株主の会社から借入がある
- （例）役員報酬の支給開始が期首から3か月を過ぎている
