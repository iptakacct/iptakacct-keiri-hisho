# 周辺システム一覧（会計システム以外）

会計システム自体は `accounting-rules.md`「会計システム」節に書く。ここには、この会社の経理・バックオフィスで触るその他のシステムを、実務の中で判明するたびに追記する（`/setup`の場でまとめて聞かない）。ID・パスワードは書かない（`credentials.md`へ、値はオーナー本人が記入）。

各行の「接続手段」は、既に共通で整備されているものを優先する。未整備のツールはclaude-in-chrome（ログイン済みブラウザ）で操作し、繰り返し使うと分かったら共通スキル化を検討する。

| 種別 | システム名 | 用途・この会社での使い方 | 接続手段 | 関連スキル・備考 |
|---|---|---|---|---|
| 請求書受領・承認 | （未設定。例：invox） | | （例：invox API＝`invox-api`スキル／ブラウザ） | 接続用ユーザーの登録有無を先に確認する |
| 請求書発行 | （未設定） | | | |
| 経費精算 | （未設定） | | | |
| 給与・勤怠 | （未設定） | | | 給与計算の手順は `work/給与計算-<会社名>.md` に記録する |
| チャット | Slack ワークスペース名：（未設定）／対象チャンネル：`#<フォルダ名>` | 作業報告の投稿先 | Slackコネクタ（都度ワークスペース切替）／常設Botが必要ならインスタンス配下の`.claude/scripts/`に置く | 自己送信メッセージは通知されない。無人通知はIncoming Webhook経由 |
| メール | （未設定） | | Gmailコネクタ等 | 対外送信は下書きまで |
| ストレージ | （未設定。例：Google Drive 領収書フォルダ／請求書保管フォルダ） | | Google Driveコネクタ等 | フォルダIDをここに記録する |

| その他 | （未設定） | | | |

## 接続の前提チェック

- 各システムで「この会社が見えるか」（ユーザー追加済みか）を、作業前に確認する。見えなければ無理に進めず、オーナーに依頼して待つ（`accounting-rules.md`に「ユーザー追加待ち」と記録）
- パスワードを使って自分でログインしない
