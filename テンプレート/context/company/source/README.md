# source/ — 受け取った資料の原本

オーナーから渡された資料（Excel・PDF・CSV・画像など）の原本をそのまま置く場所。
確認を取らずに保存してよい（`../../../.claude/rules/source-materials.md`）。

- ファイル名は内容と対象会社が分かる名前にする（例：`給与計算メモ-〇〇.xlsx`）
- **原本を置いたら、中身を必ず `context/` 配下のmdへ転記する**。バイナリはgitで差分が見えず検索もできないため、原本だけでは後から使えない
- 転記先には出典（元のパス・受け取った日）を書く
- 認証情報（トークン・パスワード・秘密鍵）は置かない
