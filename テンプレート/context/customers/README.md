# 顧客情報

事業の顧客・取引先の情報を置く場所。

**顧客の定義：売上が計上されている先**
生徒・法人・講座など単位の呼び方は事業内容に応じて変わるが、基本的には会計上「売上」が計上されている取引先を顧客として扱う。

**顧客の個人情報をこのフォルダで扱ってよいか：扱ってよい（全クライアント共通）**
氏名・連絡先など顧客の個人情報を含めて、このフォルダで管理してよい。クライアントごとに`/setup`で都度確認し直さない。

`/setup`ではまとめて質問せず、実務の中で顧客名・概要が出てきた際に、都度このフォルダに追記していく。会計データの補助科目（freee・マネーフォワード等）に売上計上先として顧客名が現れた場合も、同様にここへ追記してよい。
