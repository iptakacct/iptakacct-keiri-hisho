# 先方のClaudeへ移すときのチェックリスト

作ったもの・つないだものを、作るたびに1行足す。移すときはこの表を上から片づける。
設計と手順は `../.claude/rules/client-connection-setup.md`。

## インスタンスの中にあるもの（フォルダごと移す）

| 対象 | いまの状態（こちら側） | 移すときにやること |
|---|---|---|
| ルール・手順・会社情報 | CLAUDE.md・`.claude/rules/`・context・work | keiri-hisho を土台にして載せる |
| スクリプト・設定ファイル | `.claude/scripts/` | 転送先・作業者名・メンション先を先方の環境に書き換える |
| 元データの置き場（git管理外） | `work/` の下の取り込み先 | 移さない（先方の環境で取り直す） |

## インスタンスの外にあって、使っている共通の部品

| 対象 | 使っているところ | 移すときにやること |
|---|---|---|

## 外部サービスの接続

| 対象 | いまの状態（誰の名義か） | 移すときにやること |
|---|---|---|
| 会計ソフトのアプリ・認可 | | 先方のアプリポータルでアプリを作り、先方の担当者で認可し直す |
| チャットのボット | | 先方の管理者のアカウントで作り直すか、持ち主を移す |
| Google のシステム用アカウント | | 先方の名義で作ってあれば不要。鍵だけ先方の環境に置く |
