# 経営サマリー（経営者向けの月次資料、全クライアント共通）

担当の会社の経営者向けに、月次の経営判断の材料を1ページにまとめる。テキスト版の骨組みは `テンプレート/work/経営サマリー-YYYY-MM.md`。

## 構成

1. 今月、判断が要る1点
2. 資金の見通し（資金繰り表：直近3か月の実績と先3か月の予定。作る場合）
3. 損益
4. 未回収・未払で気になるもの
5. 備考・ご相談（税務判断のリスクがあるものだけ）

## 作る順番

1. 月次チェック（`mf-monthly-check`／`freee-monthly-check`）を流す
2. 資金繰り表を作る（作る場合）
3. テキスト版 `work/経営サマリー-YYYY-MM.md` を確定させる（内容の正）
4. HTML版 `work/経営サマリー-YYYY-MM.html` を作り、Artifactで公開する。月ごとに新しいURL、同じ月の差し替えは同じURLの更新
5. 公開・更新したら、その会社のSlackチャンネルへ独立して通知する（`output-format.md`「ダッシュボード系Artifactの更新通知」）
6. 公開履歴は会社ごとの `<インスタンス>/.claude/rules/keiei-summary.md` に書く

## 広げ方

- 1社で形を作ってから、各社の月次チェックのときに、その会社の経営サマリーを作り始める。一度に全社を作らない
- **先方への共有は、非公開で作ってから、出すかをオーナーに確認する**（試作段階のため）
- 読者は経営者。記帳の実務連絡や仕訳番号は載せない
