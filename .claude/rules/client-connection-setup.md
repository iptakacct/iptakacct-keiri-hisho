# 新しい会社の接続のセットアップ（全クライアント共通）

新しい会社の立ち上げ・接続・経理のデータの流れの把握をするときの、常に守ることをまとめる。

- **新しい会社の話が出たら、どこまでやるか（自動化まで／業務の理解だけ／使わない）をこちらから聞く**
- **権限は最初の依頼でまとめて1通で取る**（例：マネーフォワードなら、会計の管理者登録＋アプリポータルのアプリ連携〈使うサービスすべて〉・アプリ開発・システム管理）。後から小出しに頼むと先方の手間が増える。**権限の依頼は管理者へ、作業の依頼は作業者へ**出す
- 接続した後は、`monthly-onboarding.md`に沿って経理のデータの流れを把握する
- 先方に経理の流れを見せるときは、いつも標準フォーマット（`テンプレート/work/経理の流れ.html`）で作る。先方の経理だけで完遂する前提で書き、オーナー個人向けの仕組み（秘書側の自動化など）は載せない
- **こちらの名義で作った接続**（OAuthアプリ、APIキー、連携の許可など）は、インスタンスの`work/引き継ぎチェックリスト.md`に必ず1行書く。クライアントへの引き継ぎ・契約終了時に、取り消し漏れが出ないようにするため
- 認証情報は`security.md`に従い、チャットやファイルに平文で置かない
