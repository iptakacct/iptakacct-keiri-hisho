# 法人格・団体種別の略語（銀行振込データの表記読み替え、全クライアント共通）

このファイルは、使いながら追記していく場所です。銀行の振込明細・入出金摘要は、法人格・団体種別が定型の略語（カタカナ1〜3文字＋「）」）で省略されて表示される。取引先の消込・名寄せを行う際は、この略語を機械的に読み替えてから照合すること。

## 読み替えの位置ルール

同じ法人格でも、法人名の**前**に付くか**後ろ**に付くかで表記が変わる。
- 先頭に使う時：`カ）〇〇`（例：`カ）ヤマヲ` → 株式会社ヤマヲ）
- 中間／末尾に使う時：`〇〇（カ）` または `〇〇（カ`（例：`シミズウンユ（カ` → 清水運輸株式会社）

摘要の文字コード・全角半角・OCR起因のゆれ（「）」の有無、スペース有無など）は同一とみなして読み替える。
