# 新規クライアント初回ヒアリング・チェックリスト

新しいクライアントとの初回MTGで確認しておきたい項目のまとめ。`/setup`スキルの質問リストを、実際の面談で使える形に凝縮したもの。詳細な聞き方・反映先ファイルは`SKILL.md`本体を参照。

## 基本情報
- [ ] 会社名・屋号
- [ ] 事業責任者・代表者名
- [ ] 事業内容（何のサービス・商品を扱っているか）
- [ ] 開業日・事業開始時期
- [ ] 会社HP（あれば）
- [ ] 運営体制（代表1人か、スタッフがいるか。人数感）

## 経理・会計まわり
- [ ] 使用している会計システム（マネーフォワード／freee等）
- [ ] 会計システムへのアクセス方法（MCP連携できるか、ログインURLは何か）
- [ ] 銀行口座（いくつ、どこの金融機関か。ID/パスワードは聞かない）
- [ ] クレジットカード（法人カードの有無、枚数、カード会社。従業員用にプリペイドカード等があるか）
- [ ] 小口現金の有無（あれば管理者・記帳方法）
- [ ] 固定資産の有無（あれば何があり、減価償却台帳の有無）
- [ ] 在庫の有無（あれば何をどう管理しているか、棚卸のタイミング）
- [ ] 請求書支払の件数感・頻度
- [ ] 売上の計上方法（何を使って売上を記録しているか。例：会費徴収サービス等）
- [ ] 締め日・支払/入金サイト（売上の入金サイト、費用の支払サイト）

## 人事・労務まわり
- [ ] 従業員管理の状況（人数、誰が管理しているか）
- [ ] 社会保険手続きの状況（対象人数、誰が担当しているか）

## 認証情報
- [ ] 上記で挙がったシステム・口座・カードの一覧化（値〈ID・パスワード〉は聞かない。`credentials.md`に項目名だけのテンプレートを作る）

## AI秘書の役割
- [ ] このAI秘書にどこまでの業務を任せたいか（経理・総務・人事など、事業特有の業務を含む）
- [ ] 定点観測したい指標・業務分野（週次・月次まとめのカスタマイズに使う）
