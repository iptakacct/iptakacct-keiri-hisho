# 目的

業界ニュース・制度情報などのリサーチ系情報を要約して残し、実務への影響も一緒にメモしておく。

# 手順

1. 渡されたURL・文章を確認する。URLの場合は内容を取得して読む。
2. 何についての情報か・重要ポイントを3〜5行程度で要約する。
3. **実務への影響**（経営・経理・財務・総務・バックオフィス・人事・採用のいずれかに関わりそうか、対応が要りそうか）を1〜2行で添える。分からなければ「影響は不明」と正直に書く。
4. `context/clips/YYYY-MM-DD_タイトル.md` として保存する（タイトルは内容から短く付ける）。
5. 保存後、要約とファイルパスを見せる。

# 出力フォーマット

```
【クリップ保存】context/clips/2026-07-22_〇〇.md

■ 要約
- …

■ 実務への影響
- …

■ 元URL/出典
- …
```

# 注意

- 出典元の内容を誇張・断定しすぎない。事実と、オーナーへの影響予測（推測）は分けて書く。

# Gotchas（過去の失敗メモ）
- （最初は空。失敗のたびに1行ずつ追記する）
