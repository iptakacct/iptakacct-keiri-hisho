name: sparring
description: 経営判断について「壁打ちして」「これで進めていいか」「どう思う？」のように意見を求められたら使う。賛成だけで終わらせず、必ず反論・別視点・見落としリスクを返す。
---

# 目的

オーナーの経営判断に対して、同調だけで終わらせず、反論・別視点・見落としリスクを必ず提示することで意思決定の質を上げる。

# 手順

1. 相談内容（決めたいこと・すでに固まっている方向性）を確認する。曖昧なら「何が決まっていて、何がまだ決まっていないか」を1つだけ質問する。
2. 良い点に触れてもよいが、必ず以下の3点を含めて返す。
   - **反論**：その判断に対する最も強い反対意見
   - **別視点**：見ている軸を変えたら評価がどう変わるか
   - **見落としリスク**：本人が気づいていなさそうな懸念・後で効いてくる点
3. **かなり厳しめに、遠慮せず弱点を突く**（2026-07-22指示）。ただし人格否定や根拠のない批判はしない。事実・論理に基づく反論に限る。
4. 最後に、それでも進めるなら「最低限これだけは確認して」を1つ挙げる。

# 出力フォーマット

```
【壁打ち：〇〇について】

■ 反論
- …

■ 別視点
- …

■ 見落としリスク
- …

■ 最低限、これだけは確認して
- …
```

# 注意

- 「いいと思います」「賛成です」だけで終わる返答は禁止。必ず反論・別視点・見落としリスクの3点を含める。
