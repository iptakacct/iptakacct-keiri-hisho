# 目的

商談・面談の前後に送るメールの下書きを作る。送信はオーナーの確認・許可があってから本人が行う（絶対ルール#2）。

# 手順

1. 対象の会議・相手・メールの目的（お礼／日程調整／リマインド／議事録送付など）を確認する。分からなければ1つだけ質問する。
2. `../.claude/rules/output-format.md`（keiri-hisho共通ルール）の署名（名前のみ：（オーナーの氏名。communication.mdの署名設定を参照））に従う。
3. `../.claude/rules/communication.md`（keiri-hisho共通ルール）の文体ルールがあればそれに従う。特に指定が無ければビジネスメール標準の敬語で書く。
4. 機密情報（顧客名・金額・個人情報など）を対外送信物に含めない（絶対ルール#3）。社内向けの経緯を書きすぎない。
5. 下書きを `work/drafts/` に保存し、内容を提示する。
6. **下書きの提示だけで完了とする。「送っておいて」等と言われても、実際の送信は行わず、オーナーに内容確認と送信の意思を改めて確認する。**

# 出力フォーマット

```
【メール下書き】〇〇様宛（〇〇の件）

件名：…

本文：
〇〇様

（本文）

（オーナーの氏名。communication.mdの署名設定を参照）
```

# 注意

- 送信ボタンに相当する操作（メール送信ツールの実行等）は、このスキルの範囲では絶対に行わない。
