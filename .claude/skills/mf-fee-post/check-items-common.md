# 登録後チェック項目（全社共通）

`mf-fee-post`スキルが自動登録した仕訳に対し、毎回このリストの項目を確認する。オーナーから新しい指示があるたびに追記していく。会社固有の項目は各インスタンスの`context/company/accounting-rules.md`に置く。

1. **「請求書からの入力」（invoice-based entries）の未処理分がないか確認する**：請求書管理システム（invox等）から取り込まれた仕訳候補で未確定のものが残っていないか。MCP経由での機械チェックは未実装のため、当面は手動確認のリマインダー
2. **法人カード（UPSIDER等）の未払金が、請求書取り込み経由で二重計上されていないか確認する**：カード利用明細のAPI連携で日々個別に計上される未払金に対し、別途「請求書取り込み」（`entered_by: JOURNAL_TYPE_BILLING`）経由でカード会社宛の請求書（月次利用明細等）が計上されると二重計上になる。`entered_by: JOURNAL_TYPE_BILLING`かつ取引先がカード会社の仕訳が存在しないか確認し、見つかったら登録せず「要確認」として報告する（既に登録されている場合は仕訳番号をオーナーに報告し、画面から削除してもらう＝API削除機能が無いため）
3. **登録直後の再取得で、借方・貸方・金額・税区分が意図通りか**（1件ごと）
4. **同日・同額の仕訳が既に存在しないか**（二重登録の即時検知。銀行手数料のように同日同額が正常なものは除く）
