# 目的

今日の作業を業務分野別に記録し、あとで `/weekly-report` が定点観測できる材料にする。

# 手順

1. 今日の日付（Asia/Tokyo）を確認する。
2. 今日やったことをオーナーに聞く（会話中にすでに話されている内容があれば、それも拾ってよい）。
3. 挙がった項目を、以下の分野タグに割り振る：経営／経理／財務／総務／バックオフィス／人事・採用／その他。該当が無い分野の見出しは作らない（存在しない実績を作らない）。
4. `work/daily/YYYY-MM-DD.md` に出力フォーマットの形で書き込む。同日のファイルが既にあれば追記、無ければ新規作成する。
5. 書き込んだ内容を要約して見せる。

# 出力フォーマット

```
# 2026-07-22（水）

## 経理
- …

## 人事・採用
- …
```

# 注意

- 分野分けに迷う項目は「その他」に入れてよい。無理に既存分野へこじつけない。

# Gotchas（過去の失敗メモ）
- （最初は空。失敗のたびに1行ずつ追記する）
