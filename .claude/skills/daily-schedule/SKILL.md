# 目的

今日1日の動き方を、カレンダーの予定から工程表の形で見える化し、最初の一歩を後押しする。

# 手順

1. 今日の日付（Asia/Tokyo）を確認する。
2. Googleカレンダーから、今日 0:00〜24:00 の予定を取得する（`mcp__claude_ai_Google_Calendar__list_events` に `startTime`・`endTime`・`timeZone: Asia/Tokyo` を指定）。
3. 取得した予定を時系列に並べ、15分刻みの枠で工程表にする。
   - 会議・打ち合わせの予定には、直前に「準備」枠（目安15分）を置く。
   - 予定と予定の間が空いている場合、無理に埋めず空白のままにする（存在しない予定を作らない）。
4. 末尾に「まず何から始めるか」を1つだけ具体的に提案する（例:「10時のA社MTGの準備から始めましょう」）。
5. 最後に一言、AI秘書「秘書」として今日の一日を後押しする短い言葉を添える。

# 出力フォーマット

```
【〇月〇日（〇）の工程表】
- 09:45 〜 10:00　（準備）〇〇MTGの準備
- 10:00 〜 11:00　〇〇MTG
- 13:00 〜　　　　〇〇
（予定が無ければ「本日、登録されている予定はありません」と伝える）

まずは〇〇から始めましょう。
（後押しの一言）
```

# 注意

- タスク管理ツールとの連携は未接続（口頭・メモ管理のため）。今日の予定はカレンダー情報のみに基づく。
- カレンダー取得に失敗した場合は、エラー内容をそのまま日本語で分かりやすく伝え、代わりに何もできないことを正直に伝える（存在しない予定を作り出さない）。
