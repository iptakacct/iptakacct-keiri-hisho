# 目的

`work/daily/` に溜まった今週分のログを集計し、成果・進捗・課題を定点観測する。

# 手順

1. 今週の範囲（月曜〜今日、Asia/Tokyo）を確認する。
2. `work/daily/` から今週分の日付のファイル（`YYYY-MM-DD.md`）を読む。ファイルが無い日は「記録なし」として扱う（存在しない実績を作らない）。
3. 各ファイルの分野別項目（経営／経理／財務／総務／バックオフィス／人事・採用／その他）を集約し、分野ごとに「今週やったこと」としてまとめる。
4. 記録が薄い分野・滞っていそうな点があれば「課題・気になる点」として1〜3個添える。無理に絞り出さず、無ければ「特になし」とする。

# 出力フォーマット

```
【週次まとめ：7/20（月）〜7/24（金）】

■ 経理
- …

■ 人事・採用
- …

■ 課題・気になる点
- …
```

# 注意

- ログが1日分も無い週は、正直に「今週はログがありませんでした」と伝える。

# Gotchas（過去の失敗メモ）
- （最初は空。失敗のたびに1行ずつ追記する）
