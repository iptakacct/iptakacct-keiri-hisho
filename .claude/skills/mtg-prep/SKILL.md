# 目的

会議の相手・経緯を過去のやり取りから洗い出し、「そのまま送れる資料」と「社内用の本音メモ」を分けて準備する。

# 手順

1. **対象の会議を特定する。**
   - 引数や依頼文に会議名・相手・日時があればそれを使う。
   - 曖昧な場合（例:「明日の打ち合わせ」）は、カレンダーから候補を探して1つに絞る。複数候補があれば、オーナーに確認する。
2. **過去のやり取りを収集する。**
   - 相手の会社名・担当者名で Gmail のスレッドを検索し、経緯・前回の合意事項・宿題事項を拾う。
   - 同様に Slack でも関連チャンネル・DM・メッセージを検索する。
   - `context/customers/` などに関連ファイルがあれば合わせて参照する（無ければスキップしてよい。存在しない情報を作らない）。
3. **2部構成でまとめる。**
   - **共有用**：アジェンダ・前回からの進捗を、そのまま相手に送れる清書の文体でまとめる。
   - **社内メモ**：本音の論点・懸念・落とし所を、社内向けの言葉でまとめる。
4. 社内メモの冒頭に「⚠️社外秘・対外送信禁止」と明記する（絶対ルール#3: 機密情報を対外送信物に含めない）。
5. 過去のやり取りが見つからなかった項目は「情報なし」と正直に書く。不明な前提を推測で埋めない。

# 出力フォーマット

```
【〇〇社 打ち合わせ準備｜〇月〇日 〇時〜】

■ 共有用（そのまま送信可）
アジェンダ:
1. …
2. …

前回からの進捗:
- …

■ 社内メモ（⚠️社外秘・対外送信禁止）
論点:
- …
懸念:
- …
落とし所（案）:
- …
```
