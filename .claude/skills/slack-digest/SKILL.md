---

# 目的

未読Slackメッセージの中から、返信・対応が必要なものを見逃さないように洗い出す。

# 手順

1. Slackワークスペースが複数事業・複数会社で共用されている場合、`context/company/overview.md`に記載された「対象Slackチャンネル」のみを対象にする（記載が無ければワークスペース全体を対象にする）。無関係な事業のチャンネルは対象に含めない。
2. 接続中のSlackツールには「未読」を直接取得する機能が無いため、代わりに**前回 `/slack-digest` を実行した時刻以降**を対象にする（2026-07-22決定）。
   - `work/.slack-digest-last-run.json` に前回実行時刻（Unixタイムスタンプ）を記録しておき、今回はそれ以降のメッセージを検索の `after` パラメータで絞り込む。
   - このファイルが無い場合（初回）は「直近24時間」を対象にし、その旨を出力に明記する。
   - 実行の最後に、今回の実行時刻で `work/.slack-digest-last-run.json` を更新する。
3. 対象チャンネル・時刻の範囲でチャンネル・DM・グループDMのメッセージを検索する。
4. 各メッセージについて、対応要否を判定する。
   - **対応が必要**：自分宛の質問・依頼・承認待ちなど、アクションが要るもの
   - **確認だけでOK**：お知らせ・共有事項など、読むだけでよいもの
   - 明らかな雑談・自分に無関係なメンションは拾わなくてよい
5. 「対応が必要」なものを優先して上に出す。誰から・どのチャンネル/DM・要点・リンクを添える。
6. 「確認だけでOK」なものは簡潔にまとめて下に添える。
7. これは社内向けの一覧なので、顧客名・金額などが含まれていてもそのまま記載してよい（対外送信物ではないため絶対ルール#3の対象外）。ただし、ここで返信文まで作らない。返信の下書きは別途 `/meeting-email` 等で依頼されたときに行う。

# 出力フォーマット

```
【Slack未読ダイジェスト｜〇月〇日】

■ 対応が必要（〇件）
1. [#チャンネル名] 〇〇さんより：要点…（リンク）
2. …

■ 確認だけでOK（〇件）
- [#チャンネル名] 〇〇…

（未読が無ければ「未読はありません」と伝える）
```

# 注意

- 未読の判定ができない・件数が多すぎて全件見きれない場合は、正直にその旨を伝える（見た範囲だけで「全部確認しました」と言わない）。
